### Amazon Redshift Overview

- Fully managed petabyte-scale data warehouse for analytical workloads
- Columnar storage + Massive Parallel Processing (MPP)
- Loads: CSV, JSON, Parquet, ORC
- Supports SQL-based BI tools

### Cluster Architecture

- **Leader Node**: coordinates queries, aggregates results
- **Compute Nodes**: execute workload, dedicated CPU/memory/storage
- **Provisioned** vs **Serverless** deployment options

### Node Types

- **RA3**: Redshift Managed Storage (compute/storage decoupled), multi-AZ, hot on SSD/cold in S3
- **DC2**: local SSD, compute-intensive <1TB, single AZ

### Distribution Strategies

- **Key**: rows with same value on same slice — ideal for joins
- **All**: full table on every node — small frequently-joined tables
- **Even**: spread evenly — no obvious key
- **Auto**: Redshift selects optimal strategy automatically

### Advanced Features

- **Redshift Spectrum**: query S3 data without loading
- **Materialized Views**: pre-computed results with auto-refresh
- **Federated Queries**: query external PostgreSQL-compatible DBs
- **Zero-ETL**: Aurora → Redshift direct integration
- **Redshift ML**: `CREATE MODEL` SQL command → SageMaker Autopilot

### Fine-Grained Access Control

- **Column-Level Security**: `GRANT SELECT` on specific columns
- **Row-Level Security**: `CREATE RLS POLICY` with SQL conditions
- **Dynamic Data Masking**: partial masking, hashing, tokenization

### Workload Management (WLM)

- **Automatic WLM** (recommended): ML-driven concurrency and memory
- **Manual WLM**: up to 8 queues
- **Short Query Acceleration**: ML-powered prioritization for short queries

### Key Integrations

- S3: COPY (load) / UNLOAD (export) / Redshift Spectrum
- Kinesis Data Streams and MSK: low-latency ingestion into materialized views
- Glue, Lambda, DynamoDB, Aurora Zero-ETL
